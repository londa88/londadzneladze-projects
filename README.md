# Systems Programming Projects (C / C++ / Scheme)

Coursework projects focused on low-level programming, memory management and generic data structures.

| Project | Language | What it does |
|---|---|---|
| [Vector](Vector/) | C | Generic dynamic array and hash set built with `void*` and raw memory management, plus a thesaurus lookup that uses them |
| [Six-degrees](Six-degrees/) | C++ | Finds the shortest chain of shared films between two actors over a binary IMDb-style database (breadth-first search) |
| [rsg](rsg/) | C++ | Random Sentence Generator that expands grammar definitions into random text |
| [where-am-i](where-am-i/) | Scheme | Functional program that estimates a position from distance readings using points and circles |

## Build

Projects with a `Makefile` build with `make` inside their folder.
